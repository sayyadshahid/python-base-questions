==============================
COUNTING SORT – COMPLETE NOTES
==============================

DEFINITION:
-----------
Counting Sort is a NON-COMPARISON based sorting algorithm.
It sorts elements by counting the number of occurrences
of each distinct element.

It works only for NON-NEGATIVE INTEGERS.

------------------------------------------------------------

WORKING PRINCIPLE:
------------------
1. Find the maximum element in the array.
2. Create a counting array of size (max + 1).
3. Store the frequency of each element.
4. Reconstruct the sorted array using frequencies.

------------------------------------------------------------

IMPORTANT RULE:
---------------
Counting Sort does NOT compare elements.
It uses index positions as values.

------------------------------------------------------------

EXAMPLE:
--------
Input Array:
[4, 2, 2, 8, 3, 3, 1]

Step 1: Find max = 8

Step 2: Counting Array (index = value)
Index:   0 1 2 3 4 5 6 7 8
Count:   0 1 2 2 1 0 0 0 1

Step 3: Rebuild Sorted Array:
[1, 2, 2, 3, 3, 4, 8]

------------------------------------------------------------

ALGORITHM:
----------
1. Let max = maximum element in array
2. Create count array of size max+1
3. Initialize count array with 0
4. For each element x in array:
      count[x] += 1
5. Traverse count array:
      while count[i] > 0:
           place i in original array
           decrement count[i]

------------------------------------------------------------

PYTHON CODE:
------------
def counting_sort(arr):
    maxx = max(arr)
    count = [0] * (maxx + 1)

    for x in arr:
        count[x] += 1

    i = 0
    for c in range(maxx + 1):
        while count[c] > 0:
            arr[i] = c
            i += 1
            count[c] -= 1

    return arr

------------------------------------------------------------

TIME COMPLEXITY:
----------------
O(n + k)
Where:
n = number of elements
k = range of input (max value)

------------------------------------------------------------

SPACE COMPLEXITY:
-----------------
O(k)
Extra counting array is used

------------------------------------------------------------

STABILITY:
----------
Counting Sort IS a stable sorting algorithm
(if implemented carefully)

------------------------------------------------------------

ADVANTAGES:
-----------
• Very fast for small range data
• Linear time complexity
• No comparisons
• Excellent for integers

------------------------------------------------------------

DISADVANTAGES:
--------------
• Cannot handle negative numbers directly
• Memory waste if range is large
• Not suitable for floating-point numbers

------------------------------------------------------------

WHEN TO USE:
------------
• Small range of numbers
• Integer data
• When speed is critical

------------------------------------------------------------

ONE-LINE INTERVIEW ANSWER:
-------------------------
Counting Sort sorts elements by counting their frequencies
instead of comparing them.

------------------------------------------------------------

COMPARISON (EXAM):
-----------------
Bubble / Selection / Insertion → O(n²)
Merge / Quick → O(n log n)
Counting Sort → O(n + k)
