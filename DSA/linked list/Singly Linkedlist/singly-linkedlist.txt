====================================
SINGLY LINKED LIST – COMPLETE NOTES
====================================

DEFINITION:
-----------
A Singly Linked List is a linear data structure
where each element (node) contains:
• Data
• A reference (link) to the next node

Each node points ONLY to the next node in the list.

----------------------------------------------------

STRUCTURE OF A NODE:
--------------------
Each node has two parts:

| DATA | NEXT |

DATA  → stores the value
NEXT  → stores the address of the next node

The last node's NEXT points to NULL.

----------------------------------------------------

REPRESENTATION:
---------------
HEAD → [DATA | NEXT] → [DATA | NEXT] → [DATA | NULL]

HEAD stores the address of the first node.

----------------------------------------------------

WHY LINKED LIST IS USED:
------------------------
• Dynamic size (can grow or shrink)
• Efficient insertion and deletion
• No memory wastage like arrays

----------------------------------------------------

TYPES OF LINKED LIST:
---------------------
1. Singly Linked List
2. Doubly Linked List
3. Circular Linked List

(This note is for Singly Linked List)

----------------------------------------------------

BASIC OPERATIONS:
-----------------
• Traversal
• Insertion
• Deletion
• Searching
• Length

----------------------------------------------------

TRAVERSAL:
----------
Visiting each node starting from HEAD
and moving till NULL.

----------------------------------------------------

INSERTION OPERATIONS:
---------------------
1. Insertion at beginning
2. Insertion at end
3. Insertion at specific position

----------------------------------------------------

DELETION OPERATIONS:
--------------------
1. Deletion at beginning
2. Deletion at end
3. Deletion at specific position

----------------------------------------------------

ADVANTAGES:
-----------
• Dynamic memory allocation
• Easy insertion and deletion
• No need for contiguous memory

----------------------------------------------------

DISADVANTAGES:
--------------
• Extra memory for storing NEXT pointer
• No random access (must traverse)
• Slower access compared to arrays

----------------------------------------------------

TIME COMPLEXITY:
----------------
Access:        O(n)
Insertion:     O(1) (at beginning)
Deletion:      O(1) (at beginning)
Searching:     O(n)

----------------------------------------------------

APPLICATIONS:
-------------
• Implementation of stacks & queues
• Dynamic memory allocation
• Polynomial manipulation
• Undo/Redo operations
• Music playlist

----------------------------------------------------

ONE-LINE INTERVIEW ANSWER:
-------------------------
A Singly Linked List is a linear data structure
where each node contains data and a reference
to the next node in the list.

----------------------------------------------------

PYTHON IMPLEMENTATION:
---------------------

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class SinglyLinkedList:
    def __init__(self):
        self.head = None

    # Insert at beginning
    def insert_begin(self, data):
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node

    # Insert at end
    def insert_end(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return
        temp = self.head
        while temp.next:
            temp = temp.next
        temp.next = new_node

    # Traversal
    def display(self):
        temp = self.head
        while temp:
            print(temp.data, end=" -> ")
            temp = temp.next
        print("NULL")

----------------------------------------------------

EXAMPLE OUTPUT:
---------------
10 -> 20 -> 30 -> NULL

----------------------------------------------------

IMPORTANT EXAM POINTS:
----------------------
• Head stores first node address
• Last node points to NULL
• Nodes are not stored in contiguous memory
• Traversal is required for access
