====================================
DOUBLY LINKED LIST – COMPLETE NOTES
====================================

DEFINITION:
-----------
A Doubly Linked List is a linear data structure
where each node contains:
• Data
• A reference to the previous node
• A reference to the next node

Traversal is possible in BOTH directions.

----------------------------------------------------

STRUCTURE OF A NODE:
--------------------
Each node has three parts:

| PREV | DATA | NEXT |

PREV → stores address of previous node
DATA → stores value
NEXT → stores address of next node

----------------------------------------------------

REPRESENTATION:
---------------
NULL ← [PREV | DATA | NEXT] ⇄ [PREV | DATA | NEXT] ⇄ [PREV | DATA | NEXT] → NULL

HEAD → first node
TAIL → last node

----------------------------------------------------

WORKING PRINCIPLE:
------------------
• Each node knows its previous and next node
• First node's PREV = NULL
• Last node's NEXT = NULL
• Traversal can be done forward and backward

----------------------------------------------------

WHY DOUBLY LINKED LIST:
-----------------------
• Easier backward traversal
• Efficient deletion (no need to track previous manually)
• Useful in navigation systems

----------------------------------------------------

BASIC OPERATIONS:
-----------------
• Traversal (forward & backward)
• Insertion
• Deletion
• Searching

----------------------------------------------------

TRAVERSAL:
----------
Forward Traversal:
HEAD → NEXT → NEXT → NULL

Backward Traversal:
TAIL → PREV → PREV → NULL

----------------------------------------------------

INSERTION OPERATIONS:
---------------------
1. Insertion at beginning
2. Insertion at end
3. Insertion at specific position

----------------------------------------------------

DELETION OPERATIONS:
--------------------
1. Deletion at beginning
2. Deletion at end
3. Deletion at specific position

----------------------------------------------------

ADVANTAGES:
-----------
• Traversal in both directions
• Easy deletion of a node
• No need to keep track of previous node manually
• Useful for complex data structures

----------------------------------------------------

DISADVANTAGES:
--------------
• Extra memory required for PREV pointer
• More complex than singly linked list
• Slightly slower due to extra pointer handling

----------------------------------------------------

TIME COMPLEXITY:
----------------
Access:        O(n)
Insertion:     O(1) (at beginning)
Deletion:      O(1) (at beginning)
Searching:     O(n)

----------------------------------------------------

APPLICATIONS:
-------------
• Browser forward/backward navigation
• Undo/Redo operations
• Music players (previous & next song)
• LRU Cache
• Deque implementation

----------------------------------------------------

ONE-LINE INTERVIEW ANSWER:
-------------------------
A Doubly Linked List is a linked list
where each node contains data
and pointers to both previous and next nodes.

----------------------------------------------------

PYTHON IMPLEMENTATION:
---------------------

class Node:
    def __init__(self, data):
        self.data = data
        self.prev = None
        self.next = None

class DoublyLinkedList:
    def __init__(self):
        self.head = None

    # Insert at beginning
    def insert_begin(self, data):
        new_node = Node(data)
        if self.head:
            self.head.prev = new_node
            new_node.next = self.head
        self.head = new_node

    # Insert at end
    def insert_end(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return
        temp = self.head
        while temp.next:
            temp = temp.next
        temp.next = new_node
        new_node.prev = temp

    # Traversal
    def display_forward(self):
        temp = self.head
        while temp:
            print(temp.data, end=" ⇄ ")
            temp = temp.next
        print("NULL")

----------------------------------------------------

EXAMPLE OUTPUT:
---------------
10 ⇄ 20 ⇄ 30 ⇄ NULL

----------------------------------------------------

IMPORTANT EXAM POINTS:
----------------------
• Each node has two pointers (prev & next)
• First node prev = NULL
• Last node next = NULL
• Supports forward and backward traversal
• Uses more memory than singly linked list

----------------------------------------------------

DIFFERENCE: SINGLY vs DOUBLY LINKED LIST
---------------------------------------
Singly:
• One pointer (next)
• One direction traversal
• Less memory

Doubly:
• Two pointers (prev, next)
• Two direction traversal
• More memory
