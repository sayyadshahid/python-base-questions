==============================
BINARY SEARCH – COMPLETE NOTES
==============================

DEFINITION:
-----------
Binary Search is an efficient searching algorithm used to find
a target element in a SORTED array.
It works by repeatedly dividing the search interval into half.

------------------------------------------------------------

IMPORTANT CONDITION:
--------------------
⚠ Binary Search works ONLY on a SORTED array.

------------------------------------------------------------

WORKING PRINCIPLE:
------------------
1. Set low = 0 and high = n - 1.
2. Find the middle index:
      mid = (low + high) // 2
3. Compare the middle element with the target value.
4. If equal → element found.
5. If target < middle element → search left half.
6. If target > middle element → search right half.
7. Repeat until element is found or range becomes invalid.

------------------------------------------------------------

EXAMPLE:
--------
Input Array:
[10, 20, 30, 30, 50, 60]

Target Element:
50

Step 1:
low = 0, high = 5
mid = (0 + 5) // 2 = 2
arr[mid] = 30
50 > 30 → search right half

Step 2:
low = 3, high = 5
mid = (3 + 5) // 2 = 4
arr[mid] = 50
✔ Element found at index 4

------------------------------------------------------------

ALGORITHM (ITERATIVE):
---------------------
1. Initialize low = 0, high = n - 1.
2. While low ≤ high:
      a. mid = (low + high) // 2
      b. If arr[mid] == key → return mid
      c. If key < arr[mid] → high = mid - 1
      d. Else → low = mid + 1
3. If element not found → return -1

------------------------------------------------------------

PYTHON CODE (ITERATIVE):
-----------------------
def binary_search(arr, x):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2

        if arr[mid] == x:
            return mid
        elif x < arr[mid]:
            high = mid - 1
        else:
            low = mid + 1

    return -1


a = [10, 30, 20, 50, 30, 60]
a.sort()
print(binary_search(a, 50))

------------------------------------------------------------

OUTPUT:
-------
4

------------------------------------------------------------

TIME COMPLEXITY:
----------------
Best Case: O(1)
Average Case: O(log n)
Worst Case: O(log n)

------------------------------------------------------------

SPACE COMPLEXITY:
-----------------
O(1)
(No extra space used in iterative version)

------------------------------------------------------------

STABILITY:
----------
Binary Search is NOT a sorting algorithm,
so stability is NOT applicable.

------------------------------------------------------------

ADVANTAGES:
-----------
• Very fast searching algorithm
• Time complexity is logarithmic
• Efficient for large datasets
• Simple logic once understood

------------------------------------------------------------

DISADVANTAGES:
--------------
• Works only on sorted arrays
• Sorting the array may take extra time
• Not suitable for linked lists (without modification)

------------------------------------------------------------

WHEN TO USE:
------------
• When data is already sorted
• When fast searching is required
• Large datasets
• Exams and interview questions

------------------------------------------------------------

ONE-LINE INTERVIEW ANSWER:
-------------------------
Binary Search finds an element by repeatedly dividing
the sorted array into halves until the element is found.
